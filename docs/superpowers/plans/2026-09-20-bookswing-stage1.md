# 북스윙 1단계 구현 계획

**Goal:** 승인한 10개 항목을 원본 근거, 독서 노트, 지속 타이머, 기록 관리, 공유, 책장, 통계 순서로 완성한다.
**Architecture:** SQLite에 원본 의미와 타이머 상태를 보존한다. 화면은 작은 Streamlit 모듈로 나누고 모든 쓰기 검증은 임시 DB에서 수행한다.
**Tech Stack:** Python 3.9, SQLite, Streamlit 1.50, pandas, pytest/AppTest.
**Spec:** 2026-09-20 사용자가 승인한 10개 항목 및 제공한 북스윙 스크린샷.

## 제약
- 숫자 kind 0/1/2/4 유지. 원본 JSON/사진 불변. 실제 DB 변경 전 SQLite 백업.
- 모바일 푸시·SNS 인프라·카카오 API 제외. 개인용 단일 사용자 앱.
- 타인 기획문서 수정 2개 보존. 상위 저장소 변경 금지.

## 순서와 검증
- [x] 1. `migration/audit_source.py`, `lib/source_semantics.py`: status/readingNow와 날짜순 생명주기 대조. 합성 원본으로 판정 테스트 후 705권 집계. 실제 DB 보정은 원본에서 유래한 행만, 백업 후 트랜잭션 처리.
- [x] 2. `lib/notebook_ui.py`, `app.py`: 페이지·본문·기록일 카드, 최신순, 선택한 입력만 열기. AppTest에서 순서·필터·빈 화면 검증.
- [x] 3. `lib/reading.py`: DB 시작/중지/완료/취소, 중복 저장 방지. 재연결·새 AppTest 세션에서도 복구. 초 단위 저장, 통계 분은 초/60.
- [x] 4. `lib/db.py`, 기록 폼: 인용문과 선택적 생각, 현재 쪽 기본값. kind2/0 및 책 진도 불변 검증.
- [x] 5. 전체 타임라인: 책 출처·검색·유형 필터·페이지 나누기. 책 이동 AppTest.
- [x] 6. `lib/records.py`: 수정·소프트 삭제·복원. 진도는 세션 시작 쪽을 보존하고 최신 진도만 현재 쪽에 영향, 과거 세션은 독립 통계 수정. 충돌이면 거절. 합계·복원·중복 요청 테스트.
- [x] 7–8. `lib/sharing.py`, `lib/sharing_ui.py`: 출처 있는 무작위 인용구, 책 이동, 메일/복사/다운로드/미리보기, 메모 선택. URL 인코딩·개인 메모 제외·AppTest 검증.
- [x] 9. 책장: 실시간 집계, 최근 기록순, 읽는 책 미리보기/전체, 카테고리 표지. AppTest 검증.
- [x] 10. `lib/statistics.py`: 한국 시간 기준 월/연 차트, 날짜 범위, 무기록일 포함 평균. 경계 날짜·0건·삭제된 기록 제외 테스트.
- [x] 전체 회귀 테스트 및 브라우저 육안 확인. 항목별 결과와 대안/한계 문서화, 작업 기록, 명시적 파일만 커밋.

각 단위는 실패 테스트 → 구현 → 통과 검증 → 커밋 순서로 진행한다. 이 작업은 승인에 따라 같은 세션에서 순차 실행한다.
