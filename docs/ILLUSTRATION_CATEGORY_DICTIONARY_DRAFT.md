## 검토 기준

- 실제 폴더 추가·삭제·이름 변경은 이 사전에서 하지 않는다. snapshot 갱신 명령이
  폴더 이름만 반영하고 기존 aliases/keywords를 보존한다.
- `교회`, `사명`은 실제 standalone category이므로 composite category의 alias로
  넣지 않았다.
- `성경`, `말씀`, `결혼`, `이성교제`처럼 실제 폴더가 여럿인 단어는 exporter의
  legacy alias가 아니다. 새 저장값은 항상 위 canonical 값이다.
