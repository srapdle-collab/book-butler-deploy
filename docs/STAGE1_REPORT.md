## 통계와 기록 변경 규칙

- 날짜는 Asia/Seoul, 시작일과 종료일 포함. 기본 종료일은 오늘이며 미래 날짜를 선택하지 않는다.
- 쪽/일·분/일 = 선택 기간 합계 ÷ 양 끝을 포함한 일수. 기록 없는 날도 포함한다.
- 권/월·쪽/월 = 선택 기간 합계 ÷ 걸쳐 있는 달 수. 8월31일~9월1일은 2개월이다. 일부만 선택한 달도 1개월.
- 재독 완료는 회수마다 계산한다. 원본 kind6 완료 301건과 새 앱의 완료 이벤트를 집계하고 원본 kind5 시작은 제외한다.
- 새 타이머 시간은 저장된 초/60, 원본은 분. 합산은 반올림 전 값으로 하고 평균만 소수 첫째 자리 표시.
- 음수·누락 측정값은 집계에서 0으로 처리하되 원본 저장값은 변경하지 않는다.
- 삭제는 행을 지우지 않고 표시를 남긴다. 조회/검색/추억/통계/스트릭에서 제외되고 복원하면 다시 포함된다.
- 과거 진도는 독립 독서 세션으로 계산한다. 다음 세션의 시작 쪽을 자동 수정하지 않는다. 이 때문에 과거 진도 페이지 편집을 막는다.
- 현재 페이지와 맞는 최신 진도만 페이지 수정/삭제 시 현재 진도를 함께 바꾼다. 삭제 후 다른 진도를 남겼거나 상태가 바뀌면 충돌하는 복원은 거절한다.

## 기록 공유

- 책 상세의 인용구·메모 카드, 전체 타임라인, 한 장의 추억이 같은 `공유` 버튼을 사용한다. 책장에서 책을 누르면 같은 책 상세 카드로 이동한다.
- 본문은 인용문·선택적 내 생각 또는 단독 메모와 `책 제목 · 저자 · 페이지 · 기록일` 출처를 포함한다.
- 문자 링크는 RFC 5724의 `sms:?body=` 형식으로 UTF-8 퍼센트 인코딩한다. Apple 공식 SMS 링크 문서는 Safari에서 메시지 앱을 여는 `sms:`만 보장하고 본문 매개변수는 보장하지 않으므로, 본문이 채워지지 않을 때 복사 후 붙여넣기를 안내한다. 실물 iPhone Safari 실행은 이 개발 환경에서 직접 검증하지 못했다.

## 검증 범위

- pytest/AppTest 총35개 통과. 실제 입력·수정·삭제·복원은 임시 SQLite와 임시 사진 폴더로 검증.
- 실제 자료의 DB 복사본으로 책장/책 상세/타임라인/추억/통계/스트릭 6개 화면 AppTest 예외0.
- 샘플 자료의 브라우저에서 데스크톱/좁은 390px 화면 배치, 타이머 새로고침 복구·멈춤·페이지 저장, 출처와 복사 버튼의 성공 피드백 확인.
- AppTest의 업로더 조작 기능이 없어 파일 선택 경계만 대체하고, 실제 저장 함수·DB INSERT·PNG 바이트 파일 저장을 검증했다.
- 자동화 브라우저의 가상 클립보드가 페이지의 클립보드와 연결되지 않아 실제 붙여넣기 내용 대조는 미검증. 복사 실패 시 미리보기 직접 선택 안내를 제공한다.
- 메일 링크의 제목/본문은 검증했으나 외부 메일 앱의 실행·발송은 하지 않았다. 모바일 실기기 네이티브 동작 검증은 포함하지 않는다.

## 범위와 인계

모바일 푸시, SNS 계정/팔로우/공개 피드, 카카오 API는 이번 범위에서 제외했다.
앱은 단일 사용자이며 여러 사용자에게 공개하기 전에는 계정·소유권·접근 제어 설계가 필요하다.
기존 기획문서의 타인 미커밋 변경을 보존했다. 상위 저장소는 수정하지 않았고, 전용 브랜치의 작업만 커밋한다. main 자동 병합과 원격 push는 수행하지 않는다.
